## ✨ What is NexPath?

NexPath is a full-stack AI application that replaces generic career advice with a **personalized, adaptive learning path engine**. Instead of static course lists, NexPath:

1. **Converses with you** through a guided chat flow to understand your career goals, interests, current skill level, and available time.
2. **Semantically matches** your profile against a curated corpus of real learning resources using sentence-level vector embeddings.
3. **Generates a structured learning path** broken into milestones, each with specific items, difficulty labels, and explanations generated by Gemini AI.
4. **Adapts dynamically** — when you mark items as "completed" or "I struggled", it re-weights future recommendations accordingly.

## 🤖 ML Pipeline Deep Dive

### Step 1 — Corpus Preparation (`prepare_corpus.py`)

The raw dataset (`raw_courses.csv`) is cleaned and structured into a `cleaned_corpus.json` file. Each entry is tagged with a domain (`webdev`, `datasci`, `ml`) and enriched with skill tags and descriptions.

### Step 2 — Sentence Embedding (`ml_service.py`)

The ML service is a **FastAPI microservice** that:

- **Loads the corpus on startup** into memory — no database required.
- **Embeds every course's skill+description** using [`all-MiniLM-L6-v2`](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) (a compact `sentence-transformers` model that runs locally with no API key).
- **Accepts a learner query** (free-form text describing their goal and background).
- **Embeds the query** using the same model at inference time.
- **Computes cosine similarity** between the query vector and all corpus entry vectors.
- **Filters by domain** (optional) and returns the **top-K most relevant items**, sorted by similarity score.

```python
# Simplified recommendation flow
query_vec  = model.encode([query])
scores     = cosine_similarity(query_vec, corpus_embeddings)[0]
top_k_ids  = np.argsort(scores)[::-1][:top_k]
results    = [corpus[i] for i in top_k_ids]
```

**No GPU required** — `all-MiniLM-L6-v2` runs efficiently on CPU for a 3-domain corpus.

### Step 3 — Path Planning (`pathPlanner.js` → Gemini AI)

The Node.js backend orchestrates the full recommendation pipeline:

| Step | Action | Agent |
|------|--------|-------|
| 1 | Receive learner query + domain | Express Route |
| 2 | Forward to ML service → get top-K corpus matches | FastAPI ML Microservice |
| 3 | Send matches + learner context to Gemini | Gemini AI |
| 4 | Gemini **expands** the list, **re-ranks** items, **groups** them into milestones | Gemini (expand agent) |
| 5 | Gemini **generates explanations** for each item ("why this is right for you") | Gemini (explain agent) |
| 6 | Structured JSON path (milestones, items, difficulty, explanations) returned | Backend |
| 7 | Frontend renders interactive accordion milestone dashboard | React |

### Step 4 — Adaptive Feedback Loop (`/feedback` route)

When a user marks an item as **"completed"** or **"I struggled"**:
- The feedback is stored in-memory per `learnerId`.
- The next `/path` call re-weights the recommendation — completed items are deprioritized, struggled items trigger easier alternatives from the same domain.

## 🧠 AI Agents

NexPath uses **two specialized Gemini AI agents**:

### 🔍 Domain Fit Explainer Agent (`/possibilities`)
Analyzes the learner's raw chat inputs and, for each matched domain, produces a human-readable explanation of **why this domain fits their stated goals and background**. Returns a match score percentage alongside the explanation.

### 🗺️ Path Generator Agent (`/path`)
Given the top-K semantically relevant courses, this agent:
- Re-ranks and curates the items in priority order.
- Groups them into numbered **milestones** (beginner → intermediate → advanced).
- Assigns difficulty labels (`Beginner`, `Intermediate`, `Advanced`).
- Writes a personalized "why this" explanation for each item referencing the learner's stated goals.
- Outputs a structured JSON path consumed directly by the milestone dashboard.

## 🚀 Getting Started (Local Development)

### Prerequisites

- Node.js 18+
- Python 3.10+
- A Google Gemini API Key
- A Supabase project (for auth)

### 1. Clone the repository

```bash
git clone https://github.com/Kanishka780/NexPath.git
cd NexPath
```

### 2. Set up the ML Service

```bash
cd ml-service
pip install fastapi uvicorn sentence-transformers scikit-learn numpy
python ml_service.py
# Runs on http://localhost:8000
```

### 3. Set up the Backend

```bash
cd backend
npm install
# Create .env file:
echo "GEMINI_API_KEY=your_gemini_key_here" > .env
node pathPlanner.js
# Runs on http://localhost:4000
```

### 4. Set up the Frontend

```bash
cd frontend
npm install
# Create .env.local file:
echo "VITE_SUPABASE_URL=your_supabase_url" > .env.local
echo "VITE_SUPABASE_ANON_KEY=your_supabase_anon_key" >> .env.local
npm run dev
# Runs on http://localhost:5173
```
